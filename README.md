# つぼみと はな 🌸

小学1年生の国語「つぼみ」の学習に合わせた、植物のカード図鑑アプリです。20種類の植物について、**つぼみの「とい」→ 花の「こたえ」**の順にカードをめくりながら、教科書と同じ「問いと答え」の文章の組み立てを確かめられます。

- **公開先**：<https://tsubomi-learning.giga-school.com/>
- **入れるもの無し**：ブラウザで開くだけ。アカウント登録・ログイン・氏名入力の画面はありません
- **通信しない**：学習の記録を保存する仕組みはありません。外部へ送るデータもありません
- **声で読む**：ブラウザの読み上げ機能で、1年生向けにゆっくり読み上げます

## このアプリでできること

| できること | 中身 |
| --- | --- |
| 🌱 **つぼみを みる** | カードのおもてに、つぼみの画像と「これは、なんの つぼみでしょう。」の**とい**の文 |
| 🌼 **こたえを みる** | カードをおすと裏返り、咲いた花の画像と**こたえ**の文（どんなふうに咲くかの説明つき） |
| 🔊 **こえで きく** | 「こえで きく」ボタンで、といの文・こたえの文をゆっくり読み上げ（もう一度おすと止まる） |
| 🏷️ **なかまわけ** | 「すべての しょくぶつ」「にわ・みちばたの はな」「やさい・くだものの はな」の3つのタブで絞りこみ |

収録している植物は20種類です。

| なかま | 植物 |
| --- | --- |
| 🏡 にわ・みちばたの はな（12） | チューリップ／ひまわり／たんぽぽ／あじさい／バラ／さくら／コスモス／つつじ／ゆり／パンジー／カーネーション／つばき |
| 🍅 やさい・くだものの はな（8） | 菜の花／キュウリ／いちご／かぼちゃ／おくら／りんご／みかん／ブロッコリー |

## 使い方（授業での 使いかた）

1. ブラウザで公開先の URL を開きます（電子黒板でも、児童のタブレットでも同じ画面です）。
2. カードのおもてを見て、「なんの つぼみかな」と予想します。文が読みにくい子には「こえで きく」を押させます。
3. カード（または「こたえを みる」ボタン）をおすと裏返り、花の画像とこたえの文が出ます。
4. 教科書の「あさがお」「はす」「ききょう」と同じように、**はじめに「とい」、つぎに「こたえ」**という順序になっていることを確かめます。
5. タブを切りかえると、「やさい・くだものにも花が咲く」ことに気づかせる展開ができます。

読み上げは端末に入っている日本語の音声を使います。音声が入っていない端末では読み上げが動かないことがありますが、そのほかの操作はそのまま使えます。

## 素材について

`assets/` にある**画像40枚（つぼみ20枚・花20枚）は、すべて生成AIで用意した画像です**。実際に撮影した写真ではありません。本物の植物のように見えますが、実物の記録ではないので、**観察の代わりにはなりません**。実物を見る学習と組み合わせて、「こんな形だったかな」と思い出したり、その季節に見られない植物を補ったりする使い方を想定しています。

説明の文章は、教科書と同じ「とい」と「こたえ」の文型・順序にそろえて新しく書き起こしたものです（教科書本文の転載はしていません）。

## 技術構成

- HTML / JavaScript + Tailwind CSS v4、ビルドは Vite（`npm run build` で `dist/` を作ります）
- 文字は Google Fonts（Kosugi Maru / Outfit）。読み込めない場合は端末のフォントで表示されます
- 読み上げは Web Speech API（`SpeechSynthesisUtterance`、`ja-JP`・速さ 0.75）
- めくったときの音は Web Audio API でその場で合成（音声ファイルは持ちません）
- 画像は WebP（1024×1024）。`loading="lazy"` で必要になったときに読み込みます

```
index.html          画面構成（見出し・なかまわけタブ・カードの置き場・がくしゅうのポイント）
index.css           Tailwind の読み込みと、色・カードのめくりアニメーションなどの追加スタイル
index.js            カードの組み立て・めくる・読み上げ・なかまわけの絞りこみ
plants-data.js      植物20種類のデータ（名前・といの文・こたえの文・画像のパス・なかま）
public/             ビルド時にそのまま dist/ へコピーされるファイル
  assets/           つぼみと花の画像40枚（生成AIで用意した画像）
  privacy.html      プライバシーポリシー
  terms.html        利用規約
  CNAME             公開先のドメイン
vite.config.js      ビルドの設定
.github/workflows/  main へ push すると dist/ を GitHub Pages へ公開します
```

開発は `npm install` のあと `npm run dev`、公開用の書き出しは `npm run build` です。

植物を増やすときは `plants-data.js` に1件追加し、`public/assets/` に `<id>_bud.webp` と `<id>_flower.webp` を置きます。`category` は `garden`（にわ・みちばた）か `food`（やさい・くだもの）のどちらかです。画面の側は追加の作業なしで、そのままカードが増えます。

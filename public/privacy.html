要点

  • tsubomi-learning には、利用者が何かを入力する画面がありません。氏名もクラスも入力しません。
  • 学習の記録を保存する仕組みを持っていません。端末にも、制作者の側にも残りません。
  • ログインは不要です。広告もアクセス解析も入れていません。

2. 本アプリが行うこと

tsubomi-learning は、20種類の植物について、つぼみの写真と説明の文が書かれたカードを表示し、押すと裏返して花の写真と説明の文を表示するアプリです。あわせて、表示中の文をブラウザの機能で読み上げます。

  • 入力欄、ログイン、アカウント登録はありません。
  • 採点、進捗、履歴などを記録する機能はありません。
  • 制作者が運用するサーバーやデータベースはありません。

3. 取得する情報と利用目的

制作者が利用者から情報を取得することはありません。ページを表示するための通信に伴い、次の事業者のサーバーに通信の記録が残ります。

情報の種類発生する場面目的記録される場所
アクセスログ ページや画像の表示時 配信基盤（GitHub Pages）の運用およびセキュリティ確保のため GitHub 社のサーバー（制作者は個別のログを参照できません）
IP アドレスなどの通信情報 文字の書体を読みこむとき Google Fonts から書体ファイルを配信するため Google 社のサーバー（制作者は受け取りません）

いずれも、通信が成立すること自体に伴って相手方に残るものです。制作者がこれらを取得したり、個人を識別する目的で用いたりすることはありません。

4. 配信のしくみ

tsubomi-learning は、静的ファイルとして GitHub Pages から配信されています。

制作者が独自に運用するデータベースやアプリケーションサーバーはありません。そもそも送信されるデータがないため、利用者の情報が制作者の手元に集まることはありません。

5. 外部に接続する先

ページを開いたときに通信する先は、次の三つだけです。校内のフィルタリングを設定される場合の参考にしてください。

  • tsubomi-learning.giga-school.com（このページ、アプリ本体、植物の画像）
  • fonts.googleapis.com（文字の書体の指定）
  • fonts.gstatic.com（文字の書体のファイル）

書体の二つがふさがれていても、端末に入っている書体で表示されますので、学習に支障はありません。

広告、アクセス解析、外部の計測タグは一つも組みこんでいません。Google アカウントへのログインを求めることも、生成AIのサービスと通信することもありません。

6. 読み上げ機能について

「こえで きく」は、ブラウザに備わっている読み上げの機能を使っています。読み上げるのは、アプリにあらかじめ入っている植物の説明の文だけです。

ブラウザや端末の設定によっては、読み上げの処理がブラウザ提供元のサーバーで行われる場合があります。その場合に送られるのも上記の説明の文であり、利用者に関する情報は含まれません。

7. Cookie・端末への保存

Cookie は使用していません。ローカルストレージなど、ブラウザの保存領域にデータを書きこむ処理も入れていません。

端末に残るのは、ブラウザが表示を速くするために自動的に保持する一時データ（画像や書体の控え）だけです。これはブラウザの「閲覧データの削除」から消すことができます。

8. 第三者提供・外国への送信について

制作者が利用者の情報を取得していないため、第三者に販売・提供することもありません。

配信基盤（GitHub 社）と書体の配信元（Google 社）はいずれも米国の事業者であり、ページの表示に伴う通信情報がそれらのサーバーに到達します。各社での取り扱いは、それぞれの定めによります。

9. データの保存期間と削除

保存するデータがないため、保存期間の定めはありません。削除のお手続きも不要です。

端末を共用している場合でも、次に使う方に前の方の利用状況が残ることはありません。

10. 画像について

アプリで使用している植物の画像40枚は、すべて生成AIで作成したものです。実際に撮影した写真ではありません。実物の記録ではないため、観察の代わりにはなりません。実物を見る学習と組み合わせてご利用ください。

画像はあらかじめ用意したファイルを表示しているもので、閲覧中に生成しているのではありません。生成のために利用者の情報を送ることもありません。

11. 児童・生徒の利用について

学校での利用を想定しています。児童生徒が利用する場合は、教職員の指導のもとでご利用ください。

本アプリには入力欄がないため、氏名などの個人が特定される情報が入力されることはありません。

本アプリは個人が開発したものであり、学校・教育委員会の公式なサービスではありません。導入にあたっては、設置者（教育委員会等）が定める情報セキュリティポリシーや個人情報の取扱基準を必ずご確認ください。

12. 本ポリシーの変更

内容を変更する場合は、本ページの「最終更新」日を改めて掲示します。

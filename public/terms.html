要点

  • 無償でどなたでもご利用いただけます。学校での利用を歓迎します。
  • 入力も保存もしないアプリです。利用者のデータをお預かりしません。
  • 個人が公開しているものです。動作や結果を保証することはできません。

第1条（適用）

本規約は、GIGAyama（以下「制作者」）が tsubomi-learning.giga-school.com において提供する 「tsubomi-learning」（以下「本アプリ」）の利用条件を定めるものです。 本アプリを利用された方（以下「利用者」）は、本規約に同意したものとみなします。

第2条（利用料金）

本アプリは無償で提供します。ただし、通信料金等は利用者の負担となります。

第3条（本アプリの内容）

本アプリは、20種類の植物について、つぼみと花の写真および説明の文を表示し、表示中の文をブラウザの機能で読み上げるものです。

  • アカウント登録もログインも必要ありません。
  • 入力欄はありません。採点、進捗、履歴を記録する機能もありません。
  • 小学校1年生の国語の学習での利用を想定していますが、対象や用途を限定するものではありません。

第4条（データの取り扱い）

  • 本アプリは静的ファイルとして配信され、制作者が運用するサーバーに利用者のデータが送信・保存されることはありません。
  • 本アプリは利用者のデータを一切保存しません。端末のブラウザの保存領域にも書きこみません。そのため、控えを取っていただく必要のあるデータもありません。
  • 詳細はプライバシーポリシーをご確認ください。

第5条（禁止事項）

利用者は、本アプリの利用にあたり、次の行為をしてはなりません。

  • 法令または公序良俗に違反する行為
  • 他の利用者、第三者、または制作者の権利・利益を侵害する行為
  • 本アプリの配信基盤に過度の負荷をかける行為、不正アクセスを試みる行為
  • 制作者になりすます行為、または本アプリが公的機関の提供物であるかのように表示する行為
  • 本アプリの画像を、実際に撮影された植物の写真であるかのように示して用いる行為

第6条（免責事項）

  • 本アプリは現状有姿で提供されます。制作者は、本アプリの正確性、完全性、有用性、特定目的への適合性、および継続的な提供について、いかなる保証も行いません。
  • 制作者は、本アプリの利用または利用不能によって利用者に生じた損害について、責任を負いません。 ただし、制作者に故意または重過失がある場合はこの限りではありません。
  • 本アプリは、配信基盤として GitHub Pages を、文字の書体の配信に Google Fonts を利用しています。 これらの障害・仕様変更により、本アプリが利用できなくなる、または表示が変わる場合があります。
  • 読み上げは端末のブラウザの機能を用いるため、端末に日本語の音声が入っていない場合には動作しません。 読み上げの内容や読み方についても保証はできません。
  • 本アプリは、勤務先の学校・教育委員会その他いかなる組織の公式なサービスでもなく、 制作者が個人として公開しているものです。

第7条（サービスの変更・中止）

制作者は、事前の通知なく、本アプリの内容を変更し、または提供を中止することがあります。

第8条（著作権とライセンス）

  • 本アプリのソースコードは GitHub で公開しています。 ソースコードの再利用の条件は、リポジトリのライセンス表示（MIT License）に従ってください。
  • 植物の画像40枚は生成AIで作成したもので、上記ライセンスの対象外です。本アプリの画面上での表示にとどめ、 取り出して別の用途に用いることはご遠慮ください。
  • 説明の文は、教科書と同じ「とい」と「こたえ」の文型・順序にそろえて新しく書き起こしたものです。 教科書本文の転載は行っていません。
